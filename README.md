# Calculator App

A simple and clean calculator application built using HTML, CSS, and JavaScript.  
The UI is inspired by the iOS calculator design, featuring a dark theme, rounded buttons, and a responsive layout.


# Features

- Basic arithmetic operations:  
-Addition (+), Subtraction (−), Multiplication (×), Division (÷)
- Percentage (%) calculation
- Clear display (AC)
- Delete last input
- Decimal point support
- Responsive and mobile-friendly design
- iOS-style calculator UI


# features Used

- HTML– Structure  
- CSS – Styling and layout   
- JavaScript  – Calculator reponsiveness
